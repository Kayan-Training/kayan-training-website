# Event Price Tiers, Contact Numbers, Brochure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add per-event price tiers (bilingual, cards + sidebar "starting from"), per-event contact numbers (with global fallback), a brochure PDF upload/download, and a real Omani Rial currency glyph, replacing today's single hardcoded price/phone.

**Architecture:** Two new Prisma models (`EventPriceTier` + `EventPriceTierTranslation`, `EventContactNumber`) plus one new scalar (`Event.brochureUrl`), additive migration. Admin form (`event-form.tsx`) gets two new `useFieldArray` sections following the existing agenda-session/registration-field patterns exactly, plus a brochure upload control mirroring the existing cover-image uploader. `_actions.ts` persists tiers/contact numbers with the same delete-then-recreate (update) / nested-create (create) pattern already used for agenda sessions and registration fields. `queries.ts` resolves tiers with en-fallback (Trainer-translation style) and contact numbers with a global-settings fallback. Public pages (`events/[slug]` and its `training-courses/[slug]` duplicate) get a new Pricing cards section, updated sidebar, and a brochure download button. Registration re-derives price server-side from a submitted tier id, never trusting a client amount.

**Tech Stack:** Next.js (custom fork, see AGENTS.md), Prisma 7 + `@prisma/adapter-neon`, react-hook-form + zod, existing S3 presigned-upload flow (`src/lib/client/media-upload.ts`), Vitest (newly introduced — repo has no test framework today).

**Spec:** `docs/superpowers/specs/2026-09-14-event-pricing-contact-brochure-design.md`

## Global Constraints

- Additive migration only — no column drops/renames on `Event`; every new table/column must be nullable or empty-by-default so existing events with 0 tiers/0 contact numbers/no brochure render exactly as today.
- `registrationType === "external"` events: tiers stay informational-only, register button behavior is unchanged (never branch the external URL on tier selection).
- No tier date-window enforcement — validity text (e.g. "until 20 Sep") is just part of a tier's title/description string, no start/end date fields.
- No live currency conversion — `secondaryDisplayPrice` is a free-text string only.
- Registration `amount` must always be re-derived server-side from a validated `priceTierId` (or the event's flat `price` when no tiers exist) — never trust a client-submitted amount, matching the existing `eventData.price` closure-capture pattern in `register/page.tsx`.
- Both `src/app/[locale]/events/[slug]/page.tsx` and `src/app/[locale]/training-courses/[slug]/page.tsx` (and their `register/page.tsx` counterparts) get every public-facing change mirrored — they are structural duplicates today and this plan does not refactor that duplication away.
- Follow existing array-field conventions exactly: `useFieldArray` + `form.setValue(`fieldName.${index}.subfield`, value, { shouldDirty: true })` for row edits (not `form.register` with templated paths), matching the agenda-session editor.
- New card/visual sections reuse `ghost-border` + `bg-surface-container-*` + `font-mono text-*xl font-semibold` (matches `RegisterCard`'s existing price styling) — do not introduce shadcn `Card`/`Badge`, which this page never uses despite them existing in `src/components/ui/`.
- Phone numbers always render inside the existing `PhoneText` wrapper (`src/components/ui/phone-text.tsx`) to stay LTR inside RTL Arabic layout.

```prisma
model EventContactNumber {
  id        String   @id @default(cuid())
  eventId   String
  event     Event    @relation(fields: [eventId], references: [id], onDelete: Cascade)
  number    String
  labelEn   String?
  labelAr   String?
  order     Int      @default(0)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([eventId])
}

model EventPriceTier {
  id                    String                       @id @default(cuid())
  eventId               String
  event                 Event                        @relation(fields: [eventId], references: [id], onDelete: Cascade)
  price                 Decimal
  currency              String                       @default("OMR")
  secondaryDisplayPrice String?
  order                 Int                          @default(0)
  translations          EventPriceTierTranslation[]
  createdAt             DateTime                     @default(now())
  updatedAt             DateTime                     @updatedAt

  @@index([eventId])
}

model EventPriceTierTranslation {
  id          String         @id @default(cuid())
  tierId      String
  tier        EventPriceTier @relation(fields: [tierId], references: [id], onDelete: Cascade)
  locale      String
  title       String
  description String?        @db.Text

  @@unique([tierId, locale])
}
```

- [ ] **Step 2: Add the upload handler, mirroring `uploadCoverImage`**

```ts
async function uploadBrochure(file: File | undefined) {
  if (!file) return;
  if (file.type !== "application/pdf") {
    toast.error("Please select a PDF file.");
    return;
  }
  setIsBrochureUploading(true);
  setBrochureUploadProgress(0);
  setBrochureUploadStatus("");
  try {
    const media = await uploadMediaFile(file, {
      onProgress: (percent) => setBrochureUploadProgress(percent),
      onStatus: (status) => setBrochureUploadStatus(status),
    });
    form.setValue("brochureUrl", media.url, { shouldDirty: true });
    toast.success("Brochure uploaded.");
  } catch (err) {
    toast.error(err instanceof Error ? err.message : "Upload failed.");
  } finally {
    setIsBrochureUploading(false);
  }
}
```

- [ ] **Step 3: Add the markup, mirroring the cover-image dropzone**

```tsx

    onChange={(e) => uploadBrochure(e.target.files?.[0])}
  />
  {form.watch("brochureUrl") ? (
    <div className="ghost-border flex items-center justify-between rounded p-3">
      <a
        href={form.watch("brochureUrl")}
        target="_blank"
        rel="noopener noreferrer"
        className="truncate text-sm text-primary underline"
      >
        {form.watch("brochureUrl").split("/").pop()}

      <div className="flex gap-2">
        <Button

          className="cursor-pointer"
          onClick={() => brochureInputRef.current?.click()}
        >
          Replace
        </Button>
        <Button
          type="button"
          variant="destructive"
          size="sm"
```

```ts
export function resolveTierAmount(
  priceTiers: { id: string; price: number }[],
  flatPrice: number,
  submittedTierId: string,

}
```
