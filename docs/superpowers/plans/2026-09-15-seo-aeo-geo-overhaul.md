# SEO / AEO / GEO Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every page a real branded OG/Twitter share image and correct metadata, add site-wide Organization/WebSite/BreadcrumbList JSON-LD, add pricing (`offers`)/course-instance data to existing Event/Course JSON-LD, and fix the small sitemap/dead-code/llms.txt/manifest gaps found in the SEO audit.

**Architecture:** One shared metadata helper (`buildMetadataWithLocaleAlternates` in `src/lib/seo.ts`) is extended to auto-generate `openGraph`/`twitter` text metadata for every call site with zero per-page changes needed for text. A shared OG-image-builder function backs new `opengraph-image.tsx`/`twitter-image.tsx` file-convention routes at each content-type route level (events/training-courses/blog/pages) plus one shared default at the `[locale]` level that every other route (home, listings, contact-us) inherits automatically — Next.js resolves the nearest ancestor's file-convention image with no explicit `metadata.openGraph.images` needed. Two new nullable Prisma columns (`EventTranslation.seoImage`, `PageTranslation.seoImage`) let editors override the auto-generated image. JSON-LD additions (Organization/WebSite/BreadcrumbList/offers/course-instance) are pure data-transform additions to existing `jsonLdScript()` call sites.

**Tech Stack:** Next.js 16.2.4 (custom fork — `params` in file-convention image routes is a `Promise`, a real breaking change from stock Next.js docs pre-v16), `next/og`'s `ImageResponse` (Satori-based), Prisma + Neon, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-15-seo-aeo-geo-overhaul-design.md`

## Global Constraints

- Additive migration only — two new nullable columns, nothing dropped/renamed.
- `FAQPage` schema is explicitly OUT of scope (no content exists) — do not add it.
- No new PNG logo asset — the OG image builder inlines `public/brand/kayan-logo.svg`'s markup directly as JSX (Satori renders inline `<svg>` reliably; it does not reliably render `<img src="data:image/svg+xml...">`).

- [ ] **Step 2: Extend `buildMetadataWithLocaleAlternates` to build default OG/Twitter blocks**

```ts
export function buildMetadataWithLocaleAlternates(input: {
  locale: AppLocale;
  path: string;
  title: Metadata["title"];
  description: string;
}): Metadata {
  const { locale, path, title, description } = input;
  const normalized = path.startsWith("/") ? path : `/${path}`;
  const url = `${getBaseUrl()}/${locale}${normalized}`;
  const plainTitle = typeof title === "string" ? title : undefined;

  return {
    title,
    description,
    alternates: {
      canonical: url,
      languages: {
        ...Object.fromEntries(
          SUPPORTED_LOCALES.map((item) => [item, `${getBaseUrl()}/${item}${normalized}`]),
        ),
        "x-default": `${getBaseUrl()}/ar${normalized}`,
      },
    },
    openGraph: {
      title: plainTitle,
      description,
      type: "website",
      locale,
      url,
    },
    twitter: {
      card: "summary_large_image",
      title: plainTitle,
      description,
    },
  };
}
```

(`plainTitle` guards against `title` being a `{ default, template }` object, which `Metadata["openGraph"]["title"]` doesn't accept directly — when `title` is the template form, `openGraph.title`/`twitter.title` end up `undefined` and Next falls back sensibly; this only affects the `[locale]/layout.tsx` call site, which sets `title` as a template object.)

```tsx
import { readFile } from "node:fs/promises";
import { join } from "node:path";
import { ImageResponse } from "next/og";

const OG_WIDTH = 1200;
const OG_HEIGHT = 630;

let cachedFonts: { data: Buffer; name: string; style: "normal"; weight: 700 }[] | null = null;

async function loadFonts() {
  if (cachedFonts) return cachedFonts;
  const [montserrat, ibmPlexArabic] = await Promise.all([
    readFile(join(process.cwd(), "assets/fonts/montserrat-bold.ttf")),
    readFile(join(process.cwd(), "assets/fonts/ibm-plex-sans-arabic-bold.ttf")),
  ]);
  cachedFonts = [
    { data: montserrat, name: "Montserrat", style: "normal", weight: 700 },
    { data: ibmPlexArabic, name: "IBM Plex Sans Arabic", style: "normal", weight: 700 },
  ];
  return cachedFonts;
}

// Inlined from public/brand/kayan-logo.svg — paste the file's actual <svg> markup
// here as JSX (convert any kebab-case SVG attributes to camelCase for JSX, e.g.
// stroke-width -> strokeWidth), replacing this placeholder path data with the
// real file's contents. Do not reference the file via <img src>.
function KayanLogoMark() {
  return (
    <svg height="40" viewBox="0 0 200 40" width="200">
      {/* real path data from public/brand/kayan-logo.svg goes here */}
    </svg>
  );
}

export async function buildOgImage(input: {
  title: string;
  subtitle?: string;
  backgroundImageUrl?: string;
  locale: "ar" | "en";
}) {
  const { title, subtitle, backgroundImageUrl, locale } = input;
  const fonts = await loadFonts();
  const fontFamily = locale === "ar" ? "IBM Plex Sans Arabic" : "Montserrat";

  return new ImageResponse(
    (
      <div
        style={{
          width: "100%",
          height: "100%",
          display: "flex",
          flexDirection: "column",
          justifyContent: "flex-end",
          position: "relative",
          backgroundColor: "#0c0e0e",
          fontFamily,
        }}
      >
        {backgroundImageUrl && (
          // eslint-disable-next-line @next/next/no-img-element
          <img
            src={backgroundImageUrl}
            style={{
              position: "absolute",
              inset: 0,
              width: "100%",
              height: "100%",
              objectFit: "cover",
              filter: "grayscale(1)",
            }}
          />
        )}
        <div
          style={{
            position: "absolute",
            inset: 0,
            background:
              "linear-gradient(to bottom, rgba(12,14,14,0.3) 0%, rgba(12,14,14,0.7) 50%, rgba(12,14,14,1) 100%)",
          }}
        />
        <div
          style={{
            position: "relative",
            display: "flex",
            flexDirection: "column",
            padding: "64px",
            gap: "24px",
          }}
        >
          <KayanLogoMark />
          <div
            style={{
              fontSize: 56,
              fontWeight: 700,
              color: "#e2e2e2",
              lineHeight: 1.2,
              maxWidth: "1000px",
            }}
          >
            {title}
          </div>
          {subtitle && (
            <div style={{ fontSize: 28, color: "#8ce6c4", display: "flex" }}>
              {subtitle}
            </div>
          )}
        </div>
      </div>
    ),
    {
      width: OG_WIDTH,
      height: OG_HEIGHT,
      fonts,
    },
  );
}
```

(`#8ce6c4` approximates the site's teal `--secondary` accent as a static hex value, since `ImageResponse`'s Satori renderer does not support CSS custom properties / `oklch()` color functions — confirm this by checking `src/app/globals.css`'s `--secondary` value and convert to the nearest static hex/rgb if it differs from this placeholder.)

import { getEventDetailBySlug } from "@/lib/content/queries";
import { isSupportedLocale } from "@/lib/i18n/config";
import { buildOgImage } from "@/lib/og/build-og-image";

export const alt = "Event cover image";
export const size = { width: 1200, height: 630 };
export const contentType = "image/png";

export default async function Image({
  params,
}: {
  params: Promise<{ locale: string; slug: string }>;
}) {
  const { locale, slug } = await params;
  const activeLocale = isSupportedLocale(locale) ? locale : "ar";
  const event = await getEventDetailBySlug(activeLocale, slug);

  const title = event?.seoTitle || event?.title || "Kayan Training & Consulting";
  const dateLabel = event
    ? new Intl.DateTimeFormat(activeLocale === "ar" ? "ar-OM-u-nu-latn" : "en-GB", {
        dateStyle: "long",
      }).format(new Date(event.startDate))
    : undefined;
  const subtitle = event
    ? [dateLabel, event.location].filter(Boolean).join(" · ")
    : undefined;

  return buildOgImage({
    title,
    subtitle,
    backgroundImageUrl: event?.seoImage || event?.coverImage || undefined,
    locale: activeLocale,
  });
}

## Task 14: sitemap.ts — real lastModified dates

**Files:**
- Modify: `src/app/sitemap.ts`

**Interfaces:**
- No new interfaces — internal logic change only.

- [ ] **Step 1: Replace the always-`now` static-path dates with real content dates where available, omit where not**

```ts
export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const baseUrl = process.env.NEXT_PUBLIC_APP_URL ?? "http://localhost:3000";

  const entries: MetadataRoute.Sitemap = [];

  if (process.env.DATABASE_URL) {
    const [events, posts, pages] = await Promise.all([
      db.event.findMany({ where: { status: "published" }, select: { slug: true, updatedAt: true, eventKind: true } }),
      db.post.findMany({ where: { status: "published" }, select: { slug: true, updatedAt: true } }),
      db.page.findMany({ where: { status: "published" }, select: { slug: true, updatedAt: true } }),
    ]);

    const latestEventUpdate = events.reduce<Date | undefined>(
      (latest, e) => (!latest || e.updatedAt > latest ? e.updatedAt : latest),
      undefined,
    );
    const latestPostUpdate = posts.reduce<Date | undefined>(
      (latest, p) => (!latest || p.updatedAt > latest ? p.updatedAt : latest),
      undefined,
    );

    const staticPathDates: Record<string, Date | undefined> = {
      "": undefined,
      "/events": latestEventUpdate,
      "/training-courses": latestEventUpdate,
      "/blog": latestPostUpdate,
      "/knowledge": latestPostUpdate,
      "/contact-us": undefined,
    };

    for (const locale of SUPPORTED_LOCALES) {
      for (const [path, lastModified] of Object.entries(staticPathDates)) {
        entries.push({
          changeFrequency: "weekly",
          ...(lastModified ? { lastModified } : {}),
          priority: path === "" ? 1 : 0.8,
          url: `${baseUrl}/${locale}${path}`,
        });
      }

      for (const event of events) {
        const basePath = event.eventKind === "training_course" ? "training-courses" : "events";
        entries.push({
          changeFrequency: "weekly",
          lastModified: event.updatedAt,
          priority: 0.7,
          url: `${baseUrl}/${locale}/${basePath}/${event.slug}`,
        });
      }
      for (const post of posts) {
        entries.push({
          changeFrequency: "weekly",
          lastModified: post.updatedAt,
          priority: 0.7,
          url: `${baseUrl}/${locale}/blog/${post.slug}`,
        });
      }
      for (const page of pages) {
        if (page.slug === "home") continue;
        entries.push({
          changeFrequency: "weekly",
          lastModified: page.updatedAt,
          priority: 0.7,
          url: `${baseUrl}/${locale}/${page.slug}`,
        });
      }
    }
  } else {
    // No DB available — fall back to the 6 static paths with no lastModified,
    // same as before, just without the fake "now" date.
    const staticPaths = ["", "/events", "/training-courses", "/blog", "/knowledge", "/contact-us"];
    for (const locale of SUPPORTED_LOCALES) {
      for (const path of staticPaths) {
        entries.push({
          changeFrequency: "weekly",
          priority: path === "" ? 1 : 0.8,
          url: `${baseUrl}/${locale}${path}`,
        });
      }
    }
  }

  return entries;
}
```
